## About me

I design the content systems that make AI experiences work. That means giving complex information structure, governance, and a clear path through it, so the technology built on top can stay useful, trustworthy, and fast to change.

For more than 19 years, I have done that inside large organizations and regulated environments. At U.S. Bank, I rebuilt the governance model and taxonomy for a 1,000-plus-page product catalog, cutting revision cycles by 30% while improving ownership and auditability.

Now I apply the same discipline to AI-native systems: retrieval architecture, content models, agent workflows, and the guardrails that keep human judgment in the loop. I work where content strategy becomes infrastructure.

## Selected work

### d8p OS · Private

**d8p OS is a private, modular personal operating system that turns scattered information and recurring work into governed, reusable workflows.** It is built as twelve focused repositories that operate as one product: management sets direction, domain applications keep records close to the work, shared services supply memory and reusable skills, and a common foundation keeps the system consistent.

| Layer | Responsibility |
|---|---|
| **Governance and direction** | Set priorities, decisions, and operating rules across the system. |
| **Input and output** | Turn source material into useful, publishable work. |
| **Domain applications** | Keep career, household, health, and music workflows close to their records. |
| **Shared platform and foundation** | Supply durable memory, reusable skills, orchestration, administration, and consistent repository structure. |

The system is active private work. Its repositories, documentation, and case studies are intentionally not linked from this public profile.
